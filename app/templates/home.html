Which should I choose?

Analysing each material independently shows the reading no project codes, so a later material cannot be read into the vocabulary of the first — but it converges more slowly and costs a further call per material. Analysing using existing project codes reads each material against the codes and themes so far, which is cumulative comparison and is also lock-in. Either can be changed later, and the change applies to material read from then on. More in the guide.
