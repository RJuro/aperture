One job for the whole upload. Each file is laid out, read, coded and written up; then the themes are grouped over everything, a line of claims is written per theme per material, and the theme accounts and project summary are written last. It takes minutes and costs model calls — a measured two-material run made 24. You can leave the page. More in the guide.
